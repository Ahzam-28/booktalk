==========================================
BOOKIFIED - PROJECT REQUIREMENTS
==========================================

PROJECT OVERVIEW:
Bookified is a Next.js application that allows users to upload PDF books and have interactive AI conversations about them using voice and text chat.

==========================================
SYSTEM REQUIREMENTS
==========================================

- Node.js: v18.17.0 or higher
- npm: v9.0.0 or higher (or yarn/pnpm)
- Windows/Mac/Linux OS
- 4GB RAM minimum
- 500MB free disk space

==========================================
DATABASE REQUIREMENTS
==========================================

- MongoDB: v5.0 or higher
- MongoDB Connection String (Atlas or Local)

==========================================
THIRD-PARTY SERVICES
==========================================

1. Clerk Authentication
   - Account: https://clerk.com
   - API Key: NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY
   - Secret Key: CLERK_SECRET_KEY

2. Vapi AI
   - Account: https://vapi.ai
   - API Key: NEXT_PUBLIC_VAPI_API_KEY
   - Assistant ID: NEXT_PUBLIC_ASSISTANT_ID

3. Vercel Blob Storage
   - Account: https://vercel.com
   - Token: BLOB_READ_WRITE_TOKEN

==========================================
INSTALLATION INSTRUCTIONS
==========================================

1. Clone the repository:
   git clone https://github.com/Ahzam-28/booktalk.git
   cd jsm_bookified

2. Install dependencies:
   npm install
   
   or using yarn:
   yarn install
   
   or using pnpm:
   pnpm install

3. Create .env.local file with required variables:
   NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=your_key_here
   CLERK_SECRET_KEY=your_key_here
   
   NEXT_PUBLIC_VAPI_API_KEY=your_key_here
   NEXT_PUBLIC_ASSISTANT_ID=your_id_here
   
   NEXT_PUBLIC_MONGODB_URI=your_mongodb_connection_string
   
   BLOB_READ_WRITE_TOKEN=your_token_here

4. Run the development server:
   npm run dev
   
   The app will be available at http://localhost:3000

==========================================
TROUBLESHOOTING
==========================================

Issue: Infinite refresh loop
Solution: Remove 'router' from useEffect dependencies in Search component

Issue: Agent can't read messages
Solution: Enable text input in Vapi dashboard assistant settings

Issue: Turbopack error
Solution: Clear .next and .turbopack folders, restart dev server

Issue: MongoDB connection failed
Solution: Check MONGODB_URI in .env.local and network connectivity
